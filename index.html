Paso 2 — Archivos de certificado de confianza

Es el certificado público de tu CA raíz. Al instalarlo como «de confianza», el dispositivo acepta los certificados que tu CA firme. Configura la CA en el Paso 1 (crear una nueva o usar una existente) y pulsa el botón.

Cómo instalarlo en cada dispositivo
📱 iPhone / iPad (archivo .mobileconfig)
  1. Pasa el .mobileconfig al iPhone (AirDrop, correo o un enlace abierto en Safari).
  2. Ábrelo y toca «Permitir». Luego ve a Ajustes → «Perfil descargado» → Instalar.
  3. Paso imprescindible: Ajustes → General → Información → Ajustes de confianza de certificados → activa tu CA.

Sin el paso 3, iOS instala el perfil pero no confía en él. Es normal que aparezca como «No firmado».

🤖 Android (archivo .crt)
  1. Copia el .crt al teléfono.
  2. Ajustes → Seguridad (o Seguridad y privacidad) → Más seguridad → Cifrado y credenciales → Instalar un certificado → Certificado de CA.
  3. Elige el archivo .crt y confirma.

Desde Android 7, muchas apps ignoran las CA instaladas por el usuario; funciona en el navegador y en apps que lo permitan.

🪟 Windows (archivo .crt)
  1. Doble clic en el .crt → «Instalar certificado».
  2. Elige «Equipo local» (o «Usuario actual») y pulsa Siguiente.
  3. Marca «Colocar todos los certificados en el siguiente almacén» → Examinar → «Entidades de certificación raíz de confianza».
  4. Finalizar y aceptar el aviso de seguridad.
🍎 macOS (.crt o .mobileconfig)
  1. Doble clic en el .crt para agregarlo al llavero «Inicio de sesión» (o abre el .mobileconfig e instálalo en Ajustes → Perfiles).
  2. En «Acceso a Llaveros» busca tu CA, haz doble clic y despliega «Confiar».
  3. En «Al usar este certificado» elige «Confiar siempre» y guarda con tu contraseña.
⚠️

Instala solo tu propia CA. Quien tenga el .p12 de la CA puede emitir certificados que tus dispositivos aceptarán, así que guárdalo a salvo y no lo compartas.

Otras opciones con interfaz: Sideloadly (Windows/Mac), AltStore o iOS App Signer (Mac). El resultado, app-firmada.ipa, es el archivo que se instala en el Paso 2.

Requisitos
  1. La IPA tiene que estar firmada con un certificado de Apple (Development, Ad Hoc o Enterprise) y su perfil. Tu CA propia no sirve para firmar: iOS solo acepta firmas de Apple. Con perfil Ad Hoc o de desarrollo, el UDID del iPhone debe estar en el perfil.

🔐 OpenSSL — Certificado P12 para iOS/Android
GitHub Gist ↗

Genera clave privada, CSR y exporta un P12. Para iOS sube la CSR a Apple Developer, descarga el .cer y conviértelo.

# 1. Generar clave privada RSA
openssl genrsa -out private.key 2048

# 2. Crear solicitud de firma (CSR)
openssl req -new -key private.key -out certificate.csr \
  -subj "/emailAddress=tu@correo.com/CN=Tu App/O=Tu Empresa/C=MX"

# 3. Convertir certificado de Apple (.cer a .pem)
openssl x509 -in apple.cer -inform DER -out apple.pem -outform PEM

# 4. Crear archivo P12 final
openssl pkcs12 -export \
  -out certificado_app.p12 \
  -inkey private.key \
  -in apple.pem \
  -name "Certificado de Firma"

🏛️ OpenSSL — CA raíz propia + certificado firmado

Crea tu CA raíz, emite un certificado firmado por ella y empaquétalo en un P12 con la cadena completa. Instala ca.crt como certificado de confianza donde lo necesites.

# 1. CA raíz (clave + certificado autofirmado)
openssl genrsa -out ca.key 4096
openssl req -x509 -new -key ca.key -sha256 -days 3650 \
  -out ca.crt -subj "/C=MX/O=Mi Empresa/CN=Mi CA Raiz"

# 2. Clave y solicitud del certificado
openssl genrsa -out cliente.key 2048
openssl req -new -key cliente.key -out cliente.csr \
  -subj "/C=MX/O=Mi Empresa/CN=Tu App"

# 3. Firmar con la CA
openssl x509 -req -in cliente.csr -CA ca.crt -CAkey ca.key \
  -CAcreateserial -out cliente.crt -days 365 -sha256

# 4. P12 con la cadena incluida
openssl pkcs12 -export -out cliente.p12 \
  -inkey cliente.key -in cliente.crt -certfile ca.crt \
  -name "Tu App"

🐍 Python — Script completo para P12
GitHub Topics ↗

Guárdalo como generar_cert.py, instala: pip install cryptography, y ejecútalo con Python.

import datetime
from cryptography import x509
from cryptography.x509.oid import NameOID
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives.serialization import pkcs12

# Generar clave privada
clave = rsa.generate_private_key(public_exponent=65537, key_size=2048)

# Crear certificado
sujeto = x509.Name([
    x509.NameAttribute(NameOID.COUNTRY_NAME, "MX"),
    x509.NameAttribute(NameOID.COMMON_NAME, "Mi App"),
])

ahora = datetime.datetime.now(datetime.timezone.utc)
cert = (
    x509.CertificateBuilder()
    .subject_name(sujeto)
    .issuer_name(sujeto)
    .public_key(clave.public_key())
    .serial_number(x509.random_serial_number())
    .not_valid_before(ahora)
    .not_valid_after(ahora + datetime.timedelta(days=365))
    .sign(clave, hashes.SHA256())
)

# Guardar como P12
p12 = pkcs12.serialize_key_and_certificates(
    name=b"Certificado", key=clave, cert=cert, cas=None,
    encryption_algorithm=serialization.BestAvailableEncryption(b"tu_contraseña")
)

with open("certificado.p12", "wb") as f:
    f.write(p12)
print("✅ Certificado generado: certificado.p12")

📱 Keytool — Keystore para Android
GitHub Gist ↗

Incluido en Java JDK. Úsalo para generar el keystore oficial para publicar en Google Play Store.

keytool -genkeypair -v \
  -keystore app_keystore.p12 \
  -storetype PKCS12 \
  -alias mi_app \
  -keyalg RSA \
  -keysize 2048 \
  -sigalg SHA256withRSA \
  -validity 10000 \
  -dname "CN=Mi Aplicación, O=Mi Empresa, C=MX" \
  -storepass "contraseña_almacen" \
  -keypass "contraseña_clave"

# Verificar:
keytool -list -v -keystore app_keystore.p12 -storetype PKCS12

🟢 Node.js — Con node-forge
GitHub: digitalbazaar/forge ↗

npm install node-forge — Script para automatizar generación de certificados en proyectos Node.js.

const forge = require('node-forge');
const fs = require('fs');

// Generar par de claves
const keys = forge.pki.rsa.generateKeyPair({ bits: 2048 });

// Crear certificado
const cert = forge.pki.createCertificate();
cert.publicKey = keys.publicKey;
cert.serialNumber = '01';
cert.validity.notBefore = new Date();
cert.validity.notAfter = new Date(Date.now() + 365*86400000);

const attrs = [
  { name: 'commonName', value: 'Mi App' },
  { name: 'countryName', value: 'MX' }
];
cert.setSubject(attrs);
cert.setIssuer(attrs);
cert.sign(keys.privateKey, forge.md.sha256.create());

// Exportar P12
const p12Asn1 = forge.pkcs12.toPkcs12Asn1(
  keys.privateKey, [cert], 'contraseña',
  { friendlyName: 'Certificado' }
);
const p12Der = forge.asn1.toDer(p12Asn1).getBytes();
fs.writeFileSync('certificado.p12', Buffer.from(p12Der, 'binary'));
console.log('✅ Certificado generado');
